How the analysis works

Line alignment. Each original line is matched greedily to the recitation, with a one-line lookahead to recover from a missing or inserted line. A [GAP] marker occupies a line and is preserved as a gap.

Similarity. Character similarity is 2·LCS(a,b) / (|a|+|b|) after whitespace normalization and quote folding.

Code similarity. Levenshtein distance is computed between every pair of random codes; similarity is 1 - distance / max(len). A high average similarity across all pairs is a signal that the codes are not uniformly random.
