Compression

Every chapter, the model rewrites the whole story-so-far inside a word budget rather than appending to it. Appending is not compression — it just defers the problem until the context breaks. This is the part that gets better as models get better.

Two passes, one paste

The model plans before it writes, and the plan is emitted first so the order is checkable. Planning after writing is just describing what you already did.

Save

Book as HTML is the readable one: title page, contents, every chapter, the illustrations inline, one file that opens in any browser and prints as a book. The save file is the machine's copy — settings, threads, the compressed summary, the slate.

The folderchecking

One folder is one book: book.json for the settings, the cast and the compressed story so far; one file per chapter; the illustrations as loose SVGs; and the whole thing again as book.html and story.md. Reconstruct reads the chapter files back, so the folder is the book rather than a backup of it.
